usage: registry_append.py [-h] [--manifest MANIFEST] [--id ID]
                          [--description DESCRIPTION] [--value VALUE]
                          [--unit UNIT] [--class EVIDENCE_CLASS] [--n N]
                          [--formula FORMULA] [--artifact ARTIFACT]
                          [--artifact-sha256 ARTIFACT_SHA256]
                          [--script SCRIPT] [--reference REFERENCE]
                          [--registry REGISTRY] [--dry-run] [--verify-all]

Append a manifest-bound entry to results/registry.json.

options:
  -h, --help            show this help message and exit
  --manifest MANIFEST   campaign manifest path
  --id ID               registry entry id
  --description DESCRIPTION
                        what the number measures
  --value VALUE         the measured value
  --unit UNIT           unit of the value
  --class EVIDENCE_CLASS
                        M-HW | M-HOST | C | S | E
  --n N                 sample size
  --formula FORMULA     formula, when the value is computed
  --artifact ARTIFACT   artifact path (must be listed in the manifest)
  --artifact-sha256 ARTIFACT_SHA256
                        expected artifact sha256
  --script SCRIPT       script that produced the value
  --reference REFERENCE
                        manuscript section that uses the value
  --registry REGISTRY
  --dry-run
  --verify-all          verify every manifest-bound entry
